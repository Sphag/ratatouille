<h1 align="center">Ratatouille</h1>

<p align="center">Меню, покупки и готовка на неделю — в Telegram.</p>

Ratatouille помогает заранее составить рацион, собрать список продуктов и приготовить еду на неделю за одну сессию в выходные. Вместо ежедневного вопроса «что приготовить?» — готовое меню и понятный план покупок и готовки.

Основной интерфейс — Telegram Mini App на русском языке. Бот в чате открывает приложение и отправляет напоминания и сводки. Первая версия рассчитана на одного пользователя.

## Планируемые возможности первой версии

- **Меню на неделю или 28 дней.** Ручная сборка и автоматический подбор без AI; режим A/B или ограничение повторов блюд.
- **Библиотека рецептов.** Добавление, редактирование и выбор рецептов, допущенных пользователем к автоматическому подбору.
- **Калории и БЖУ.** Ручной ввод значений на порцию и дневных целей, суммирование по меню и пересчёт при замене блюда.
- **Покупки и готовка.** Общий список продуктов, перечень партий с количеством порций и чек-листы «куплено» и «приготовлено».
- **Напоминания и календарь.** Настраиваемые уведомления о готовке и разморозке в Europe/Moscow; экспорт событий в ICS для ручного импорта.

Меню и изменения сохраняются после подтверждения пользователя.

## Запуск и развёртывание

Созданы HTTP-сервер, хранение в SQLite, расчётная основа меню и формы библиотеки рецептов, ручного меню, автоматического предложения и замены с пересчётом, покупки, партии готовки и чек-листы для локальной разработки. Telegram-бот ещё разрабатывается. Сервер — Python 3.13 с FastAPI, клиент — React и TypeScript.

Проверенный локальный запуск — WSL/Linux x86_64, Git, curl и Node.js 24. Из корня проекта:

```bash
# Если Node.js 24 ещё не установлен:
bash tools/mcp/install-node.sh
# При первой установке открыть новый терминал, затем:
node --version
npm --version
bash tools/dev/setup.sh
npm --prefix frontend run build
bash tools/dev/uv.sh run --locked uvicorn ratatouille.app:app --host 127.0.0.1 --port 8000
```

Открыть [http://127.0.0.1:8000](http://127.0.0.1:8000). Токен Telegram для этого каркаса не требуется. Установка загружает uv 0.12.23 и Python 3.13.16, создаёт окружение и устанавливает зависимости по обоим lockfile.

База создаётся отдельно, когда требуется работа с данными:

```bash
bash tools/dev/uv.sh run --locked python -m ratatouille.database
```

По умолчанию это `data/ratatouille.sqlite3`; другой путь задаётся переменной окружения `RATATOUILLE_DB_PATH`. Команда применяет миграции Alembic и допускает повторный запуск. `.env` автоматически не читается. Стартовый экран и проверка процесса работают без базы. Основной процесс до появления Telegram-аутентификации не открывает личные данные.

Для локальной библиотеки и ручного планирования выполнить:

```bash
bash tools/dev/uv.sh run --locked python -m ratatouille.local_app --init
npm --prefix frontend run build
bash tools/dev/uv.sh run --locked python -m ratatouille.local_app
```

На [http://127.0.0.1:8000](http://127.0.0.1:8000) доступны добавление и изменение рецептов, архив, восстановление и явный допуск к подбору, ручное меню на 7 или 28 дней, режимы A/B и ограничения повторов, дневные цели КБЖУ, автоматическое предложение из явно допущенных рецептов и подтверждение/отмена черновика. Стартовые 18 карточек нужно проверить перед импортом; импорт не включает допуск автоматически. Профиль и БД создаются только с `--init`; повторная инициализация сохраняет профиль. Процесс работает на loopback и предназначен для локальной разработки до подключения Telegram.

Для разработки оставить локальный процесс запущенным, а в другом терминале выполнить `npm --prefix frontend run dev`. Интерфейс будет доступен на [http://127.0.0.1:5173](http://127.0.0.1:5173); запросы `/api/` идут на Python-сервер.

```bash
# Все проверки и сборка клиента:
bash tools/dev/check.sh
# Автоматическое форматирование:
bash tools/dev/uv.sh run --locked ruff format
npm --prefix frontend run format
```

Проверка работающего сервера: `curl http://127.0.0.1:8000/api/health`. Подробности структуры, переменных и запуска в Windows и Docker — в [архитектуре](docs/ARCHITECTURE.md). Постоянное развёртывание на VPS, HTTPS и настройка бота появятся в следующих задачах.
